# mauve-bitwig-theme

My old mauve theme for Bitwig Studio, since some people asked for it. Made on Bitwig 6.1.7.

## Install

1. Get the [Bitwig Theme Editor](https://github.com/Berikai/bitwig-theme-editor) and quit Bitwig.
2. Open the editor and point it at Bitwig's `bitwig.jar` (on macOS: `/Applications/Bitwig Studio.app/Contents/Java/bitwig.jar`).
3. Load `mauve.bte` and apply it, then start Bitwig.

Bitwig updates replace its jar, so apply it again after updating.
